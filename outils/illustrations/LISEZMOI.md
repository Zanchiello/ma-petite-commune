# Illustrations du site

- `dessins.py` : les dessins en SVG (style A « ligne claire » pour l'accueil et les articles, style C « carte et données » pour Observer). Les couleurs passent par les variables du site (`--pl-ink`, `--pl-accent`…), donc les dessins suivent le mode clair et le mode sombre.
- `integrer.py` : insère les dessins dans les pages. À lancer sur des pages qui n'en ont pas encore.

Dessins originaux créés pour Ma Petite Commune le 2026-11-13 : aucune licence tierce.
